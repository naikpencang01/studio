# **App Name**: KasirKu

## Core Features:

- Autentikasi Pengguna: Login (email/password) dengan peran (admin, kasir).
- Layar Kasir POS: Menambahkan item, kuantitas, modifikasi, diskon, checkout (pembayaran tiruan).
- Penyimpanan Transaksi: Menyimpan transaksi ke Firestore dengan listener waktu nyata.
- CRUD Produk: Membuat, membaca, memperbarui, dan menghapus produk (dengan unggah gambar ke Storage).
- Laporan Penjualan Harian: Membuat laporan penjualan harian sederhana.
- Sinkronisasi Offline: Mode offline dan sinkronisasi data saat terhubung kembali.
- Pembuatan Deskripsi Produk Otomatis: Membuat deskripsi produk secara otomatis menggunakan tool AI saat produk baru ditambahkan.

## Style Guidelines:

- Skema warna gelap untuk tampilan modern dan nyaman di mata.
- Warna utama: Ungu (#A093E7) untuk kesan elegan dan profesional.
- Warna latar belakang: Abu-abu gelap (#1E1E1E) untuk kontras yang baik.
- Warna aksen: Hijau limau (#BFFF00) untuk tombol aksi dan sorotan penting.
- Font untuk judul: 'Space Grotesk', sans-serif, untuk tampilan modern dan tegas.
- Font untuk badan teks: 'Inter', sans-serif, untuk keterbacaan yang optimal.
- Ikon minimalis dan intuitif untuk navigasi dan tindakan pengguna.
- Tata letak responsif yang cocok untuk berbagai ukuran layar (desktop, tablet, ponsel).
- Animasi halus untuk memberikan umpan balik visual dan meningkatkan pengalaman pengguna.
